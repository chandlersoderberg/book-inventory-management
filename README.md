# 📚 Book Inventory Management System

A modern React application for managing book inventory with CRUD operations.

## ✨ Features

- ✅ CRUD Operations (Create, Read, Update, Delete)
- ✅ API Integration (Google Books API)
- ✅ Responsive Design
- ✅ Form Validation
- ✅ Book Details Page
- ✅ Clean UI with Tailwind CSS

## 🛠️ Tech Stack

- React 18
- React Router
- Axios
- Tailwind CSS
- Vite

## 📦 Installation
```bash
# Clone repository
git clone https://github.com/chandlersoderberg/book-inventory-management.git
cd book-inventory-management

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🚀 Build & Deploy
```bash
# Build for production
npm run build

# Deploy to Vercel/Netlify
```

## 📁 Project Structure
```
src/
├── components/    # Reusable components
├── pages/         # Home & BookDetails
├── services/      # API integration
├── utils/         # Validation logic
└── App.jsx        # Main routing
```
